Monthly compliance workflow
Step 1 — Payroll run (25 May 2026)
Submit Salary Slips for May
Saudi Monthly Payroll  Salary Slip
Payroll Manager opens Saudi Monthly Payroll for May 2026. All active employees are populated with their salary components. GOSI deductions, loan installments, and any approved penalties are already included. Manager reviews and submits — ERPNext Salary Slips are created for all employees.
AUTO Salary Slips submitted. GOSI Contribution records for Saudi nationals auto-populated from payroll. WPS/Mudad group appears on the Payroll Entry form.
Step 2 — WPS submission (by 1 Jun 2026, within 7 days)
Preview WPS File → Submit WPS to Mudad → Check Status
Payroll Entry  Mudad / WPS
From the May Payroll Entry, Payroll Manager clicks Preview WPS File in the WPS/Mudad group. The SAMA SIF is built from all submitted Salary Slips. After reviewing employee count (e.g., 47 employees, total SAR 642,800), clicks Submit WPS to Mudad. Mudad processes the upload and returns a WPS reference number (e.g., WPS-2026-0548). Manager clicks Check WPS Status — result: Compliant.
AUTO All three API calls (Preview, Submit, Status) are logged to Government Portal Sync Log with status = Success and the Mudad reference number. The send_wps_correction_due_alerts scheduler stops firing for this period.
7-day deadline: Payroll ran 25 May — WPS must be submitted by 1 Jun. Late submission triggers fines up to SAR 10,000 and can block new visa applications.
Step 3 — GOSI submission (by 15 Jun 2026)
Open GOSI Contribution → Submit to GOSI → Get reference → Verify payment_status = Paid
GOSI Contribution  GOSI API
Payroll Manager opens the GOSI Contribution record for May 2026. Contributions for Saudi nationals (10% employee + 12.5% employer) are already calculated. Clicks Submit to GOSI. The GOSI API accepts the submission and returns a reference number (e.g., GOSI-REF-20260531-4421). Manager then opens the employer account via Get Employer Account to confirm total due, then clicks Contribution Certificate to download the official PDF for Finance records.
AUTO GOSI reference number saved to the Contribution record. sync_monthly_gosi scheduler will confirm payment_status = Paid on the next daily run after the bank transfer clears.
Monthly batch option: If you have many employees, use Submit Monthly Batch instead of submitting individually — it transmits all May contributions in a single GOSI API call.
Step 4 — GOSI registration check
Open Employee → GOSI group → GOSI Member Status
Employee  GOSI API
For any newly onboarded Saudi national employee (e.g., a new hire who started in May), the Payroll Manager opens their Employee record, scrolls to the GOSI group, and clicks Register Employee. After GOSI confirms registration, clicks GOSI Member Status to verify the membership is active and the correct contribution rate is applied. Result logged to Government Portal Sync Log.
AUTO Registration confirmed. GOSI deduction will be applied automatically in the next payroll run for this employee.
Step 5 — Iqama verification (ongoing)
Open Employee → Muqeem group → Verify Iqama
Employee  Muqeem
PRO or HR Compliance Officer opens the record for an expatriate employee (e.g., James Mathew's replacement, EMP-0205). Clicks Verify Iqama in the Muqeem group. Muqeem API returns live status: Active, expiry 15 Feb 2027. The Work Permit / Iqama record is updated automatically. Manager also clicks Exit Re-entry Status to confirm the employee has no exit re-entry visa that might affect business travel plans.
AUTO Both calls logged to Government Portal Sync Log. sync_expiring_iqamas daily scheduler will alert HR automatically when the 90-day window approaches in Nov 2026.
Step 6 — Audit trail review
Verify Government Portal Sync Log for the month
Portal Sync Log
Payroll Manager opens HR Suite → Saudi Portals → Government Portal Sync Log. Filters by date range (May 2026). Confirms all calls show Status = Success: Mudad WPS Submit, GOSI contribution submissions, GOSI member registrations, and Muqeem Iqama verifications. Any Failed entries are investigated and retried. The log is saved as the compliance audit trail for May 2026.
Monthly compliance achieved: WPS submitted within 7 days (Compliant). GOSI contributions submitted before the 15th. All active Iqamas verified. Audit trail complete in Government Portal Sync Log.
Salary Component Override — Quick Reference

Need to change one salary component for one employee — without rebuilding their entire Salary Structure? Use the inline override icons on the Salary Structure Assignment.

Clock icon — History
Opens a history dialog with all previous values for this component — filterable by year, with full audit rows.
Pen icon — Set override
Click the pen icon on any salary field → set a new value with an effective date and optional notes → saves a SalaryComponentOverride record. Future-dated overrides stay Pending until the date arrives.
Example: Ahmed's housing allowance increases from SAR 3,500 to SAR 4,200 effective 1 July 2026. Click the pen icon on Housing Allowance in his Salary Structure Assignment, enter the new amount and date, add a note referencing the promotion letter. The July payroll will pick up the new amount automatically — no amendment to the Salary Structure needed.
