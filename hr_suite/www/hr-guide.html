The HR system, from hiring to final settlement

This guide walks through one employee's whole time with the company, in the order it actually happens. Each stage shows you the real screen, what to type, and what the system does next. No technical knowledge needed.

12 stages Real screenshots from the test system Written for HR staff

How to use this guide

Read it once end to end, then come back to the stage you need.

Every stage is laid out the same way, so you always know where to look:

  • Where to find it — the exact menu path, in a blue bar.
  • What it is for — one or two plain sentences.
  • What to do — numbered steps, in order.
  • A picture of the real screen — so you can match what you see.
  • What happens next — what the system does on its own once you save.
Two words you will see a lot Draft means saved but not final — you can still change it. Submitted means final — the system now acts on it, and to change it you must cancel and amend. Money and leave balances only move on Submit.
Screens in this guide come from the test system The names and figures you see in the pictures are test data on sft-uat. Your live system will show your own people and your own numbers.

The employee journey

Everything in this guide hangs off one line: a person joins, works, gets paid, and one day leaves.

Hire→First day→Employee file→ Pay setup→Attendance→Leave→ Deductions→Payroll→Appraisal→ Exit

Everything starts from one place. The HR Suite workspace is the front door: quick actions on top, then the full list grouped into Employee Management, Leave & Overtime, and Payroll.

The golden rule of this system Enter a fact once, in the right place, and every later screen picks it up on its own. Three unpaid leave days typed into a Leave Application become 23 paid days on the payslip without anybody doing the arithmetic. If you find yourself typing the same number twice, stop — something is set up wrong.

Stage 1Hiring someone

From an open job to a signed offer.

📍 Where: HR Suite → Recruitment workspace

The hiring chain has six steps, and the system already has a screen for each one:

Job Requisition→Job Opening→Job Applicant→ Interview→Job Offer→Employee

Raising a vacancy

  1. Job Requisition — the request to hire. Department, designation, how many people, and why.
  2. Job Opening — the advertised role, created once the requisition is approved.
  3. Applicants come in against that opening as Job Applicant records.

Interviews that score the same things

An Interview Round holds the skill list and the pass mark. Every interviewer on that round scores the same skills out of 5, so two candidates can actually be compared.

  1. Create the Interview Round once — name it, add the Expected Skill Set rows, set the average rating you expect.
  2. Add the interviewers.
  3. For each candidate, create an Interview against that round.
  4. Each interviewer fills their own Interview Feedback with a score per skill.
Before you can send anything to a candidate Offers, interview invitations and rejections all go out by email. Email is not switched on yet — see Not switched on yet. Until it is, the system will record the offer but will not send it.

Stage 2The first day

Turning an accepted offer into a person with a checklist.

📍 Where: HR Suite → Employee Onboarding

An Employee Onboarding Template is your joining checklist, written once and reused for everyone in that role. Each row is a task, who owns it, when it starts, and how many days it takes.

  1. Build one template per role — for example "New warehouse staff".
  2. When someone accepts, create an Employee Onboarding from that template.
  3. The system raises a project with dated, owned tasks. Each owner sees their own task.
  4. When onboarding is complete, it creates the Employee record for you.
Why bother with a template Because nothing gets forgotten. The IT account, the locker key, the safety induction and the bank details all become tasks with a name against them, instead of living in somebody's head.

Stage 3The employee file

One record per person. Everything else in this guide points back at it.

📍 Where: HR Suite → Employee

This is the single most important screen in the system. If it is wrong, payroll is wrong, leave is wrong and every report is wrong.

Identity and work country

Scroll down the employee record to Identity & Work Country. This is where nationality, the National ID / CPR number and the work country live.

These fields exist but are mostly empty today Only one employee currently has nationality, CPR and work country filled in. This is a data-loading job, not a software job — see Not switched on yet.

Loading many people at once

Do not type twenty people in by hand. Use Data Import: download the template, fill the spreadsheet, upload it once.

  1. Make sure Department, Designation, Branch and Grade exist first — the import points at them.
  2. Download the Employee template from Data Import.
  3. Fill it in. One row per person.
  4. Upload, check the preview, then run it.
Order matters An import that points at a department or grade that does not exist yet will fail that row. Create the lists first, import people second.

Employee documents

Passport, CPR, contract, certificates — each has a document type, an expiry date, and its own row.

Stage 4Setting their pay

Until an employee has a salary structure assigned, payroll cannot pay them.

📍 Where: HR Suite → Salary Structure Assignment

Two pieces:

  • Salary Structure — the recipe. Which earnings and which deductions, and how each is worked out. Built once per pay pattern.
  • Salary Structure Assignment — the link between one employee, one structure, and one base amount, from a date.
  1. Open Salary Structure Assignment and choose the employee.
  2. Pick the salary structure.
  3. Enter the Base — the monthly basic figure in Bahraini dinars.
  4. Set From Date. Payroll uses whichever assignment is in force for the month being run.
  5. Submit. A draft assignment is invisible to payroll.
A pay rise is a new assignment, not an edit Never change the base on an old assignment — that rewrites history. Create a new assignment with the new base and the date it starts from. The old one stays as the record of what was paid before.

Stage 5Attendance and shifts

Who was in, who was not, and which hours they were meant to work.

📍 Where: HR Suite → Attendance / Shift Type / Holiday List

The working week

A Holiday List defines the days nobody is expected in. It holds the weekly off day and the public holidays, and payroll uses it to work out how many working days are in a month.

Public holidays are missing The 2026 list has 52 Fridays and no Bahrain public holidays. Add them with Add Local Holidays before the first live payroll, or those days will be treated as normal working days.

Shifts

A Shift Type is a start and end time with a name. Assign it to people so the system knows what "on time" means for them.

  1. Create the shift with its start and end time.
  2. Give each employee a Default Shift on their employee record, or create Shift Assignment rows for a period.
  3. Only then can the system judge late arrivals and overtime.

Recording attendance

There are three ways in, and you only need one:

MethodHow it worksBest for
Employee Check-inA device or app posts each punch; the shift turns punches into attendanceDay to day, once a device is connected
Attendance recordOne row per person per day, entered or importedCorrections and small teams
Attendance RequestThe employee asks, a manager approvesForgotten punches, work from site

Overtime

An Overtime Request records extra hours and works out the money for you from the employee's basic pay and the overtime multiplier.

  1. Pick the employee and the date.
  2. Enter Overtime Hours. Normal plus overtime cannot exceed 12 hours in a day.
  3. The system fills the hourly rate from the current basic salary and calculates the amount.
  4. Set Approval Status to Approved, then Submit.

Stage 6Leave

Record an absence once, and the payslip already knows about it.

📍 Where: HR Suite → Leave Application / Leave Allocation

How a balance appears

Nobody types in a leave balance. It arrives through a chain:

Leave Type→Leave Policy→Leave Period→ Policy Assignment→Leave Allocation
Already done for you The leave year, the policies and the allocations are set up. You should not need to create allocations by hand.

Applying for leave

  1. Open Leave Application and choose the employee.
  2. Pick the Leave Type. The balance shows on screen — you cannot spend more than is there.
  3. Enter From and To dates. Tick Half Day if it is half a day.
  4. Write the reason. Future you will want to know.
  5. Approve and Submit.

What happens to the pay

This is the part worth understanding, because it is where the system saves you the most work.

  • Paid leave — balance drops, pay does not change.
  • Leave Without Pay — the days are removed from payment days, and the pay drops in proportion.
  • Partially paid leave — a fraction of a day's pay, set on the leave type.

Stage 7Loans and deductions

Money owed to the company, collected by the payroll run instead of by memory.

📍 Where: HR Suite → Employee Loan / Employee Penalty / Additional Salary

Employee Loan

Agree the loan once and the instalments collect themselves.

  1. Create the loan: employee, loan amount, and the instalment amount or number of instalments.
  2. The system builds the repayment schedule — one row per month.
  3. Get it approved, then Submit.
  4. Every payroll run picks up the instalment that is due and puts it on the payslip as a deduction.
  5. The outstanding balance reduces itself as each payslip is submitted.
This is the ticket that started it all The complaint was that a loan instalment had to be remembered and typed in every month. It does not. Agree it once here and the payslip collects it, reduces the balance, and puts it back if the payslip is cancelled.

Other things that change the pay

Use thisForDirection
Employee LoanA loan or advance repaid over monthsDeduction, scheduled
Employee PenaltyA fine against a penalty typeDeduction, one off
Additional SalaryA bonus, allowance or one-off deductionEither, one month or recurring
Overtime RequestExtra hours workedEarning
Salary AdjustmentA correction to an agreed figureEither
Which one do I use for a bonus? Additional Salary. Pick the employee, pick the salary component, enter the amount and the payroll date. It appears on that month's payslip and nowhere else. Do not edit the salary structure for a one-off — that changes it for everybody on that structure.

Stage 8Running payroll

Look before you leap. Check the whole month on one screen, then run it.

📍 Where: HR Suite → Payroll Preview, then Payroll Entry

Step one: Payroll Preview

This is the screen the whole payroll ticket was about. Before a single payslip exists, Payroll Preview shows everything already booked against every employee for the month — earnings, deductions, loan instalments, leave, penalties — pulled live from the source documents.

  1. Create a Payroll Preview for the company and the month.
  2. Press Refresh Allocations. The system reads the source documents again.
  3. Read the banner at the top. It either says ready, or it tells you what is missing.
  4. Work through the Summary: number of employees, employees with issues, total earnings, total deductions, net estimate.
  5. Open the Allocations table. Every line names the document it came from.
StatusMeaningWhat to do
ReadyNothing blockingCreate the Payroll Entry
With issuesAt least one employee is missing something payroll needsFix the source record, refresh, look again
Not RefreshedFigures may be stalePress Refresh Allocations
Nothing on this screen is stored Payroll Preview holds no figures of its own. It rebuilds from your documents each time you refresh, so it can never quietly disagree with them.
The gate While a preview has blocking issues, the Create Payroll Entry button is not there. That is deliberate. You cannot start a payroll run on broken data by accident.

Step two: Payroll Entry

Once the preview is clean, press Create Payroll Entry. The filters you used carry across.

  1. Check the company, the dates and the list of employees pulled in.
  2. Submit. The system creates one draft Salary Slip per employee.
  3. Open a few payslips and check them against the preview.
  4. Submit Salary Slips. This is the point of no return — the accounting entry is made and loan balances move.
  5. Make the bank payment entry, and generate the WPS Submission file.
Payroll Preview→Payroll Entry→Draft payslips→ Submit→Accounting entry→WPS file
Check before you submit, not after Cancelling submitted payslips means cancelling the accounting entry too. Five minutes in Payroll Preview is cheaper than an hour of reversals.

Stage 9Appraisals

The Steel Force appraisal form, on screen, with the scores added up for you.

📍 Where: HR Suite → Appraisal

The paper form has been rebuilt inside the system. Fifteen criteria, each scored 1 to 5 by the appraiser and again by the reviewer, side by side.

  1. Create an Appraisal for the employee and the appraisal cycle.
  2. Fill the header: type of report, review date, evaluation period, years of experience.
  3. Score each of the 15 criteria from 1 to 5 in the appraiser column.
  4. The reviewer scores the same criteria in their own column.
  5. Totals out of 75 and the grade band are worked out for you.
  6. Submit, then print.
Two rules the form enforces A score must be between 1 and 5 — nothing else is accepted. And if the reviewer disagrees with the appraiser, the reviewer must write a comment. Disagreement without an explanation is not allowed through.
Mid-term and annual can both exist You can run a mid-term review and an annual review in the same year for the same person, and both are kept. Set Type of Report to tell them apart.

Stage 10Permits and LMRA

Bahrain work permits, with the renewal window watched for you.

📍 Where: HR Suite → Work Permit Iqama

One record per permit. It holds the permit number, the country it was issued in, and the expiry date.

  1. Create the record against the employee.
  2. Choose the Work Country. Bahrain permits do not ask for an Iqama number — that is a Saudi field.
  3. Enter the permit number and the expiry date.
  4. Submit. The system now watches the expiry date.
CountryWhat it is calledRenewal window
BahrainLMRA work permit60 days before expiry
Saudi ArabiaIqamaPer Saudi rules
You get told before it expires A daily job checks permits and raises expiry alerts inside the renewal window for that country, so a permit does not lapse because a date sat in a spreadsheet nobody opened.
The LMRA monthly fee is not set The system can carry the monthly LMRA fee per employee, but the amount has deliberately been left blank — see Not switched on yet. Confirm the figure and who it applies to before switching it on.

Stage 12Leaving the company

Notice, clearance, end-of-service money, final settlement.

📍 Where: HR Suite → Termination Notice / End of Service Benefit
Termination Notice→Exit Interview→Exit Clearance→ End of Service Benefit→Final Settlement

Giving notice

  1. Create the Termination Notice: employee, reason, notice date and last working day.
  2. Submit it. The system starts the exit chain and can raise the Final Settlement for you.
  3. Run the Exit Interview and record the answers.
  4. Work through Exit Clearance — company property, IT accounts, outstanding loans.

End of service benefit

The gratuity is calculated from the joining date, the last working day, the last basic salary and the reason for leaving. You do not work it out by hand.

Settle the loan first If the employee still owes a loan, that balance has to be cleared against the final settlement. Check Employee Loan before you pay anything out.

Letters and documents

📍 Where: HR Suite → HR Letter

Salary certificates, employment letters, NOCs and warning letters come from templates, so the wording is the same every time and the employee's details are filled in for you.

  1. Set up an HR Letter Template once per letter type.
  2. Create an HR Letter, pick the employee and the template.
  3. Check the merged text, then print or save as PDF.
